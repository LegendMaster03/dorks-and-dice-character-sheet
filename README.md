# Dorks & Dice Character Sheet

Character Sheet is the player-facing Dorks & Dice tool for building and managing full digital characters for the project's hybrid D&D ruleset.

The main Dorks & Dice Site owns canonical character identity, account ownership, lifecycle, and campaign-character associations. Character Sheet owns the rich digital sheet and character-building state attached to the Site-owned `CharacterId`.

The tool will integrate with Rules Core for normalized rules concepts and will run as an Embedded Module using the Site's Tool Host architecture.

Implementation work should normally occur on feature branches and be reviewed before merging to `main`.
